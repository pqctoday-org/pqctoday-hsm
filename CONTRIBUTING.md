# Feedback and contributions

Thank you for your interest in this project.

## Feedback is welcome

Please send bug reports, questions, ideas and suggestions through
[GitHub Issues](https://github.com/pqctoday-org/pqctoday-hsm/issues) or
[GitHub Discussions](https://github.com/pqctoday-org/pqctoday-hsm/discussions).

Security vulnerabilities: follow [SECURITY.md](SECURITY.md) and do **not**
open a public issue.

All participants follow the [Code of Conduct](CODE_OF_CONDUCT.md).

## Code changes are made only by the maintainer

This project does not accept outside code. Pull requests from outside the
project are thanked and closed without being merged. If a pull request
contains a good idea, the maintainer may write the change independently.
Describe the idea in an issue instead.

## Use of feedback

By sending feedback, you agree that PQC Today, LLC may use it freely, in any
version of the project, including commercially licensed versions.

## For the maintainer

Build, test and release notes are in [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md)
and [RELEASING.md](RELEASING.md).
